# 文字数カウント結果テンプレート

`{{変数名}}` を実際の値で置き換えて出力すること。

---

## 文字数カウント結果

| パターン | 改行（\n \r） | スペース（半角・全角・タブ） | 文字数 |
|----------|--------------|------------------------------|--------|
| ①        | 含む         | 含む                         | {{p1}} 文字 |
| ②        | 含む         | 除く                         | {{p2}} 文字 |
| ③        | 除く         | 含む                         | {{p3}} 文字 |
| ④        | 除く         | 除く                         | {{p4}} 文字 |

（内訳）改行: {{newlines}}文字　半角スペース: {{half_spaces}}文字　全角スペース: {{full_spaces}}文字　タブ: {{tabs}}文字

---

| 変数 | 意味 |
|------|------|
| `{{p1}}` | 改行・スペース両方含む総文字数 |
| `{{p2}}` | 改行含む・スペース除く |
| `{{p3}}` | 改行除く・スペース含む |
| `{{p4}}` | 改行・スペース両方除く（実質文字数） |
| `{{newlines}}` | 改行文字の合計個数 |
| `{{half_spaces}}` | 半角スペースの個数 |
| `{{full_spaces}}` | 全角スペースの個数 |
| `{{tabs}}` | タブの個数 |
