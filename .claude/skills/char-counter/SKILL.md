# 文字数カウントスキル

## バンドルファイル構成

```
char-counter/
├── SKILL.md                    ← このファイル（メイン指示）
├── scripts/
│   └── count_chars.py          ← Pythonカウントスクリプト（推奨）
└── assets/
    └── output_template.md      ← 出力テンプレート定義
```

### スクリプトを使う場合（推奨）

Pythonが使える環境では、手動計算せず必ずスクリプトを実行すること。

```bash
python scripts/count_chars.py "カウントしたいテキスト"
```

出力テンプレートの詳細は `assets/output_template.md` を参照。

---

ユーザーから渡されたテキストの文字数を、以下の **4パターン** で出力する。

## 除去対象文字の定義

### 改行文字（2種）
| 記号 | Unicode | 説明 |
|------|---------|------|
| `\n` | U+000A | LF（ラインフィード） |
| `\r` | U+000D | CR（キャリッジリターン） |

### スペース類（3種）
| 記号 | Unicode | 説明 |
|------|---------|------|
| ` ` | U+0020 | 半角スペース |
| `　` | U+3000 | 全角スペース |
| `\t` | U+0009 | タブ |

## 出力する4パターン

| # | 改行（\n \r） | スペース類 | 説明 |
|---|------------|-----------|------|
| ① | 含む | 含む | 入力そのままの総文字数 |
| ② | 含む | 除く | 改行は残しスペース類3種を除いた文字数 |
| ③ | 除く | 含む | 改行を除きスペース類は残した文字数 |
| ④ | 除く | 除く | 改行・スペース類すべてを除いた実質的な文字数 |

## 計算ロジック（Python）

```python
NEWLINES = {'\n', '\r'}           # U+000A, U+000D
SPACES   = {' ', '　', '\t'}      # U+0020, U+3000, U+0009

p1 = len(text)
p2 = len([c for c in text if c not in SPACES])
p3 = len([c for c in text if c not in NEWLINES])
p4 = len([c for c in text if c not in NEWLINES | SPACES])
```

1文字ずつ判定すること。`strip()` や `replace(' ', '')` だけでは全角・タブが漏れる。

## 出力フォーマット

```
## 文字数カウント結果

| パターン | 改行（\n \r） | スペース（半角・全角・タブ） | 文字数 |
|----------|--------------|------------------------------|--------|
| ① | 含む | 含む | X 文字 |
| ② | 含む | 除く | X 文字 |
| ③ | 除く | 含む | X 文字 |
| ④ | 除く | 除く | X 文字 |

（内訳）改行: X文字　半角スペース: X文字　全角スペース: X文字　タブ: X文字
```

## 注意事項

- コードブロックで囲まれた入力はブロック記号を除いた中身のみカウント
- 「〇〇文字以内か確認して」の場合は4パターン出力後に条件判定を添える
- 入力が空の場合はすべて 0 文字と出力する
