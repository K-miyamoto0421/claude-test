# SEOブログライタースキル

## 📥 入力情報

**必須:**
1. **タイトル** — キーワードを含めたブログタイトル
2. **ターゲットキーワード** — SEOのメインキーワード
3. **目標文字数** — 例: 2000文字

**オプション:** 対象読者、強調ポイント

---

## 🔧 実行ステップ

### ステップ1: キーワード分析
- メインキーワード
- バリエーション（3〜5個）
- LSIキーワード（3〜5個）

### ステップ2: 記事構成

```
H1: タイトル（メインキーワード含有）
  導入文（最初の100文字以内にメインキーワード）
  H2: セクション1（キーワードバリエーション含有）
    H3: サブセクション
  H2: セクション2〜3
  H2: まとめ（メインキーワード復唱）
```

### ステップ3: メタディスクリプション
- 120〜160文字
- 最初の50文字以内にメインキーワード

### ステップ4: 本文執筆
- キーワード密度: メイン1〜2%、全体2〜3%
- 段落は3〜5文
- 具体例を2〜3個含める

### ステップ5: char-counterで計測・調整

**判定基準（パターン④: 改行・スペース除去後）:**

| 条件 | アクション |
|------|-----------|
| T×0.9 ≤ C ≤ T×1.1 | ✅ 完了 |
| C < T×0.9 | 拡張（セクション追加・具体例補足） |
| C > T×1.1 | 圧縮（冗長表現削除・セクション統合） |

最大5回繰り返す。

### ステップ6: 最終出力フォーマット

```markdown
## 最終記事情報

**タイトル:** [タイトル]
**メタディスクリプション（[文字数]文字）:** [本文]

**キーワード分析:**
- メイン: [キーワード]
- バリエーション: [一覧]
- LSI: [一覧]

**文字数カウント結果:**
| パターン | 改行 | スペース | 文字数 |
|①|含む|含む|X文字|
|②|含む|除く|X文字|
|③|除く|含む|X文字|
|④|除く|除く|X文字|

**目標達成:** 目標[T]文字 / 実測[C]文字 / 達成率[%] ✅

---
## 記事本文
[完成した記事]
```

## ✅ SEOチェックリスト

- [ ] H1×1、H2×3〜5、各H2にH3配置
- [ ] メタディスクリプション120〜160文字
- [ ] 導入文の100文字以内にメインキーワード
- [ ] パターン④が目標値±10%以内
