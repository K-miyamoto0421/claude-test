# /count — 文字数カウント

char-counterスキルを使って、ユーザーが指定したテキストの文字数を4パターンで出力する。

## 動作

1. ユーザーからカウント対象のテキストを受け取る
2. char-counterスキルの計算ロジックに従い1文字ずつカウントする
3. 改行・スペース有無の4パターンを表形式で出力する
4. 内訳（改行・半角スペース・全角スペース・タブの個数）を補足する

## 出力例

```
## 文字数カウント結果

| パターン | 改行（\n \r） | スペース（半角・全角・タブ） | 文字数 |
|----------|--------------|------------------------------|--------|
| ① | 含む | 含む | X 文字 |
| ② | 含む | 除く | X 文字 |
| ③ | 除く | 含む | X 文字 |
| ④ | 除く | 除く | X 文字 |

（内訳）改行: X文字　半角スペース: X文字　全角スペース: X文字　タブ: X文字
```
