## このリポジトリについて

ClaudeCodeの学習・実験用プロジェクトです。SubAgents・Skills・Commandsなどの機能を、
実際にコードを書きながら体系的に習得することを目的としています。

## ファイル構成

- `calculator.py` … 四則演算モジュール（型バリデーション済み）
- `sample_ml.py` … 線形回帰のスクラッチ実装
- `website/` … 練習用のWebページ（HTML/CSS/JS）
- `.claude/` … プロジェクト設定・Skills・Commandsなど（詳細は `CLAUDE.md` 参照）

## 実行方法

```bash
python calculator.py
python sample_ml.py
```
